# 🇺🇦 Add to NotebookLM

Розширення Chrome для імпорту YouTube відео, веб-сторінок та коментарів в Google NotebookLM.

## ✨ Можливості

- 📄 **Додавання поточної сторінки** одним кліком
- 🎬 **Імпорт YouTube** — відео, плейлисти, канали
- 💬 **Парсинг коментарів YouTube** — збереження обговорень у NotebookLM
- 📦 **Масовий імпорт** — кілька посилань або вкладок одразу
- 🗑️ **Масове видалення джерел** з нотатників
- 👥 **Підтримка кількох Google акаунтів**
- 🌍 **Багатомовний інтерфейс** — українська, російська, англійська
- 🎨 **Сучасний дизайн** — світла та темна теми
- 🔒 **Покращена безпека** — автооновлення токенів, валідація даних

## 🌐 Підтримувані мови

- 🇺🇦 **Українська** (uk)
- 🇷🇺 Русский (ru)
- 🇬🇧 English (en)

Мова автоматично визначається за налаштуваннями браузера або може бути змінена в Налаштуваннях.

## 📥 Встановлення

1. Завантажте або клонуйте репозиторій
2. Відкрийте `chrome://extensions/`
3. Увімкніть «Режим розробника» (Developer mode)
4. Натисніть «Завантажити розпаковане розширення» (Load unpacked)
5. Виберіть папку з розширенням

## 🚀 Використання

### Базове використання

1. Увійдіть в [NotebookLM](https://notebooklm.google.com)
2. Натисніть на іконку розширення
3. Виберіть нотатник і натисніть «Додати»

### YouTube

#### Додавання відео
- **Відео** — додає поточне відео
- **Плейлист** — додає всі відео з плейлиста
- **Канал** — додає видимі відео з каналу

#### Парсинг коментарів
1. Відкрийте відео на YouTube
2. Натисніть на іконку розширення
3. Натисніть «Парсити коментарі»
4. Виберіть режим (Топ/Всі) та ліміт
5. Дочекайтеся завершення

### Масовий імпорт

#### З посилань
1. Відкрийте Bulk Import (іконка 📦)
2. Вставте посилання (по одному на рядок)
3. Виберіть нотатник
4. Натисніть «Імпортувати посилання»

#### З вкладок браузера
1. Відкрийте Bulk Import
2. Перейдіть на вкладку «Browser Tabs»
3. Виберіть потрібні вкладки
4. Натисніть «Імпортувати вибрані вкладки»

### Налаштування

Відкрийте Settings (⚙️) для налаштування:
- **Мова інтерфейсу** — українська, російська, англійська
- **Google акаунт** — вибір облікового запису
- **Темна тема** — перемикання світлої/темної теми
- **Автовідкриття** — відкривати нотатник після додавання
- **Масове видалення** — кнопка видалення в NotebookLM

## 🎨 Дизайн

Розширення має сучасний, мінімалістичний дизайн:
- ✨ **Glassmorphism** — ефект матового скла
- 🌓 **Світла та темна теми** — автоматичне перемикання
- 🎯 **Плавні анімації** — приємна взаємодія
- 📱 **Адаптивний інтерфейс** — зручний на різних екранах

## 🔒 Безпека (v1.2.0)

- ⏱️ **Rate Limiting** — обмеження частоти запитів (500ms)
- 🔄 **Автооновлення токенів** — кожні 30 хвилин
- ✅ **Валідація даних** — перевірка походження, URL, ID
- 🔁 **Retry логіка** — автоматичні повторні спроби при помилках
- 🌍 **Локалізовані помилки** — зрозумілі повідомлення трьома мовами
